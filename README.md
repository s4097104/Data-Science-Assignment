RMIT Data Science Assignment - Task 1

This repository contains the code and dataset used for the predictive modeling section of the assignment.

Contents:

    churn_analysis.py - Python script for preprocessing, training Decision Tree & kNN models.

    online_retail_customer_churn.csv - The source dataset.

How to run:

    Ensure Python and pandas, scikit-learn are installed.

    Run the script in Google Colab or a local environment.
